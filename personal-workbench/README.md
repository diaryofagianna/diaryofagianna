# diaryofagianna · Personal Workbench

A gentle, local-first productivity workspace inspired by Morandi Workbench V1.2.

## Features
- Overview dashboard and progress summary
- Today planner with morning, afternoon, and evening sections
- Task manager with due dates, priorities, categories, search, and completion
- Four-quadrant Eisenhower view
- Monthly calendar with custom events
- Text-based mind map canvas
- Local knowledge base and notes
- Pomodoro focus timer
- Habit check-ins
- Weekly review and shareable summary
- Morandi-inspired light/dark themes
- JSON export and restore

## Data and privacy
All user data is stored in the current browser's localStorage. There is no account system, server database, or automatic cross-device sync configured. Export regular JSON backups before clearing browser data or changing devices.

## Deploy
This folder is configured as a standalone static Vercel project. Set the Vercel project's Root Directory to `personal-workbench`. No build step is required; Vercel serves `index.html`.

## Independence
This application is a separate project. It does not modify or share data with The Little Life Planner / Little Days.
